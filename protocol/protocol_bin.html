二进制高速模式与文本模式共享同一功能集,但用紧凑二进制帧 + CRC16 传输,面向自动化/大流量。连接后页面自动发送 BIN ENTER 进入二进制模式(回 OK BIN 后切换);退出用系统命令 MODE_EXIT(0x0F) 或 RESET。模式不自动混用;若失步,可重新插拔或 RESET。

🧩 帧格式

偏移大小字段说明
01SOF0xCB,固定帧起始标记
11TYPE0x01 CMD / 0x02 RESP / 0x03 ERR / 0x04 EVT / 0x05 DATA / 0x06 DATA_END
21OP操作码(命令编号;流/事件中为流标识)
31FLAGSbit0=1 表示还有后续帧(分片);其余保留
4-52LEN载荷长度,u16 小端(上限默认 4096)
6-72SEQ请求序号,u16 小端;响应原样回显;事件/流=0
8..LENPAYLOAD载荷(小端编码)
..+LEN2CRC16CCITT(0x1021,初值 0xFFFF),对偏移 0~(7+LEN) 计算
编码:通道/电平/枚举见各命令;数值一律小端;二进制数据原样传输(无需 HEX 编码)。
