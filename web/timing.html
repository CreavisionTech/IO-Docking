未连接板卡

板端自主时序 · PPS + 触发 + NMEA

配置一次，由板卡持续产生脉冲与串口时间报文。浏览器无需定时同步波形，断开 USB 控制连接也无需页面继续调度。

1 Hz 秒脉冲1–100 Hz 触发独立 UTC 校时可选开机运行

01 / 输出配置

触发输出通道（至少一个；bit0–3 对应 PWM1–4）。注意：“触发频率”只作用于这里勾选的触发通道；PPS 通道永远输出 1 Hz，没有频率参数。想让 PWM1 输出 10 Hz：把 PWM1 勾入触发通道，并把 PPS 通道换到另一路（如 PWM2），PPS 与触发不能是同一路。

脉宽至少 100 μs；PPS 小于 1 秒；触发脉宽小于 floor(1,000,000 / Hz)。PWM2 / PWM3 共用片，其他运行中的 PWM、TICK 或渐变可能导致 E_BUSY。

02 / NMEA 时间报文

应用配置 / 应用并启动 会先自动发送 TIMING STOP（运行中改参会被固件拒绝 E_BUSY，需停止后重启以重新对齐 UTC 整秒）。启动使用全局配置；若 PWM2/3/4 通道上有其他运行中的 PWM、TICK 或渐变仍会直接报 E_BUSY，请先自行停止。

03 / 独立 UTC 校时

点击后在实际发送时读取电脑的 Unix 微秒时间，发送 SYNC … UTC。精度受电脑时钟及 USB 延迟影响。波形运行不依赖浏览器周期校时。

04 / 开机运行

保存会定义 SEQ DEF name "TIMING START"，替换现有单一命名序列槽，并持久化全局配置与开机选择。序列本身不携带配置。SAVE 在 TIMING 运行时返回 E_BUSY。

尚未读取 BOOT STAT
保存动作的完整顺序
TIMING STOP
TIMING CFG …
TIMING NMEA …
SEQ DEF name "TIMING START"
BOOT SEQ name
SAVE
TIMING START

任一步失败即停止后续操作；可能已有部分配置生效。保存失败不会自动重启。关闭开机运行依次执行 TIMING STOP、BOOT OFF、SAVE。
